# Tooling used

- Existing Impeccable: visual direction, craft floor, independent finish review.
- Official GSAP ScrollTrigger and performance skill guidance: https://github.com/greensock/gsap-skills (MIT instructions; runtime separately licensed).
- Blender Agent Studio modeling/animation workflow reference: https://github.com/ifBars/blender-agent-studio (MIT). The asset builder is original local Python; no external MCP or plugin was installed.
- Three.js web guidance: https://github.com/cesartevisual/threejs-skills (MIT), checked against the actual installed package.
- Content audit: independent review of exact site text against original repository source.

No researched agent pack was installed globally. No paid modeling provider was enabled. Code dependencies and fonts are locked in package-lock.json. Blender 5.2.1 LTS is the installed and tested asset runtime.

The approved plan pins the visual world and asks for one desktop/mobile concept board and storyboard, overriding the skill's generic three-direction selection round. The board was reviewed for silhouette, hierarchy and mobile translation before detailed modeling. The scene is implemented in Blender/WebGL as explicitly requested, rather than reproducing the mockup as raster-only artwork.
